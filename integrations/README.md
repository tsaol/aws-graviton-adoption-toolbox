# integrations

How to call existing tools instead of rebuilding them (planned for v0.1):

| Stage | Tool |
|---|---|
| Find workloads | graviton-readiness, Graviton Savings Dashboard |
| Dependency scan, SIMD, container images | [Arm MCP Server](https://github.com/arm/mcp) / Kiro Graviton Migration Power |
| Java code changes | AWS Transform custom (Java x86 to Graviton) |
| Language-specific migration | [aws-graviton-getting-started skills](https://github.com/aws/aws-graviton-getting-started/tree/main/tools/skills) |

Each entry pins the version it was tested with.
